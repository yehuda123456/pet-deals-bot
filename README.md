# בוט דילים של AliExpress לטלגרם

הבוט מחפש מוצרים דרך ה-API של AliExpress Affiliate, ולכן לכל מוצר יש קישור שותפים עם עמלה. הוא מסנן לפי הנחה, ירידת מחיר והשוואה לשוק, ושולח את הטובים לערוץ.

## התקנה
1. `pip install -r requirements.txt`
2. מעתיקים את `.env.example` ל-`.env` וממלאים אותו:
   - **TELEGRAM_BOT_TOKEN**: יוצרים בוט ב-@BotFather.
   - **TELEGRAM_CHAT_ID**: מוסיפים את הבוט כאדמין בערוץ, עם הרשאת פרסום. המזהה הוא `@שם_הערוץ` או מספר שמתחיל ב-`-100`.
   - **ALI_APP_KEY ו-ALI_APP_SECRET**: נרשמים ב-portals.aliexpress.com ואז ב-open.aliexpress.com, ויוצרים אפליקציה עם הרשאת Affiliate API.
   - **ALI_TRACKING_ID**: ה-tracking id מלוח השותפים.
3. מתאימים את `config.json`: נושאי חיפוש, ספי סינון ותדירות.

## הרצה
- `python bot.py --dry-run` מדפיס את הדילים בלי לשלוח, כדי לבדוק את הסינון.
- `python bot.py --once` מריץ סבב אחד ושולח.
- `python bot.py` רץ ברצף, עם סבב כל `interval_minutes`.

## הערות
- ההשוואה ל"מוכרים אחרים" מחשבת חציון מחירים של תוצאות אותו חיפוש, ולכן מילות חיפוש ספציפיות נותנות תוצאות טובות יותר.
- היסטוריית מחירים נבנית עם הזמן ב-`deals.db`, ולכן "ירידת מחיר" תתחיל לעבוד רק אחרי כמה סבבי ריצה.
